
# Cash2Bank 💸

**A digital cash redemption platform prototype.**

Cash2Bank explores how users could redeem digital cash vouchers and transfer funds into their bank accounts without visiting a physical collection point.

## Project Goals

- Simplify digital voucher redemption.
- Validate voucher codes and redemption status.
- Explore secure digital payment workflows.
- Build a foundation for future banking API integrations.

## Current Features

- Responsive web interface.
- Demonstration voucher validation.
- Success and error messages.
- Sample voucher codes for testing.

## Technology Stack

- HTML5
- CSS3
- JavaScript

## Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Demo Voucher Codes

| Code | Expected result |
|---|---|
| `DEMO123` | Valid demonstration voucher |
| `DEMO456` | Valid demonstration voucher |
| `USED789` | Previously redeemed |
| `WRONG123` | Voucher not found |

## Important Disclaimer

This is an educational portfolio prototype. It does not process real payments, connect to banks, or redeem real financial vouchers. All voucher data is simulated.
